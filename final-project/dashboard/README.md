# Streamlit Dashboard for Marketing Incrementality

A dark-themed interactive dashboard built with Streamlit and Plotly.

## 🚀 Quick Start

### Option 1: Local Run

```bash
# Navigate to dashboard folder
cd dashboard_streamlit

# Install dependencies
pip install -r requirements.txt

# Run the dashboard
streamlit run app.py
```

Open http://localhost:8501

### Option 2: Deploy to Streamlit Cloud (Free!)

1. Push your project to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repo
4. Set the main file path to: `dashboard_streamlit/app.py`
5. Click Deploy!

## 📊 Features

- **Overview**: All KPIs at a glance + summary charts
- **DiD Analysis**: Parallel trends visualization
- **PSM Analysis**: Covariate balance love plot
- **Synthetic Control**: Actual vs synthetic comparison
- **Business Impact**: Interactive calculator with live updates

## 🎨 Theme

Dark fintech-inspired design with:
- Background: #09090b (charcoal)
- Accent: #c8ff00 (lime green)
- Cards: #27272a with subtle borders

## 📁 Data

The dashboard reads from `../output/*.json` files generated by:

```bash
python run_analysis.py
```

If no data files are found, it uses sample data for demo purposes.
